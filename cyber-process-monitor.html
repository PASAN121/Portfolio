What it does

Watch the system.
Find the abnormal.

Process Monitoring

Enumerates running processes and collects information about their current activity, including process identifiers, names and resource usage.

Resource Tracking

Tracks CPU and memory usage so resource-heavy processes can be identified and investigated.

Threshold Detection

Compares observed resource usage against predefined thresholds and classifies activity into normal, warning and alert states.

Activity Logging

Records monitoring results into a CSV log so activity can be reviewed later instead of disappearing when the monitoring session ends.

process_monitor.py 
import psutil
import csv
import time

CPU_THRESHOLD = 75
MEMORY_THRESHOLD = 75

for process in psutil.process_iter(
    ['pid', 'name', 'cpu_percent', 'memory_percent']
):

    try:

        info = process.info

        cpu = info['cpu_percent'] or 0
        memory = info['memory_percent'] or 0

        if cpu > CPU_THRESHOLD:
            status = "ALERT"

        elif cpu > 50:
            status = "WARN"

        else:
            status = "NORMAL"

Why it matters

Small tool.
Security mindset.

Process monitoring is useful because it turns raw system activity into something that can be investigated. A security analyst may need to understand which processes are running, what resources they consume, and whether unusual activity deserves further investigation.

This project connects Python programming with system monitoring, detection logic, threshold-based alerting and security logging. It is a small implementation of concepts that appear in larger endpoint monitoring and security systems.
