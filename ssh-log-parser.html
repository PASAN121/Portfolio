SSH Log Parser

Turns messy SSH authentication logs into structured JSON incident reports — regex parsing, per-source failure aggregation, clean machine-readable output.

pythonregexdefaultdictjson

What it does

Raw logs are unstructured text — useless at scale until you parse them. This tool reads an SSH auth log and extracts the events that matter, then aggregates and exports them as structured data.

It uses regex to pull failed-login events and their source IPs, a defaultdict to count failures per IP without boilerplate, and writes a JSON report that another tool (or a SIEM) can consume. This is the plumbing behind log-driven detection.

How it works

Under the hood

  1. Read the logStreams the auth log line by line.
  2. Regex-extract eventsMatches failed-login lines and captures the source IP from each.
  3. Aggregate with defaultdictCounts failures per IP as a running tally, no key-existence checks needed.
  4. Export JSONWrites a structured report — IPs, counts, verdicts — ready for downstream use.
parser.py -> report.json
$ python parser.py auth.log -o report.json
# structured output:
{
  "203.0.113.42": { "failures": 18 },
  "192.0.2.55":   { "failures": 9 }
}
report written: 12,408 lines parsed
Why it matters

Regex and log parsing are non-negotiable SOC analyst skills — most of the job is extracting signal from oceans of log text. Producing JSON instead of printed text is the difference between a script and a tool that plugs into a real pipeline.
