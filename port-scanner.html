Port Scanner

A multi-threaded TCP port scanner built on raw sockets — the fundamentals living under tools like nmap, written from scratch to actually understand them.

pythonsocketsthreadingtcp

What it does

Every network service listens on a port. Reconnaissance — the first phase of any engagement — starts with finding which ports are open on a target, because open ports are the doors you probe next.

This scanner attempts a TCP connection to each port in a range. A successful handshake means the port is open; a refusal or timeout means it's closed or filtered. Threading runs many attempts in parallel so a full sweep takes seconds, not minutes.

How it works

Under the hood

  1. Take a target + rangeAccepts a host and a range of ports to test.
  2. Attempt connectionsFor each port, opens a TCP socket and tries to connect.
  3. Read the resultConnection succeeds = open; refused/timed out = closed or filtered.
  4. ParalleliseThreads fan the work out across many ports at once for speed.
scanner.py
$ python scanner.py 192.168.1.10 -p 1-1000

Why it matters

Writing your own scanner forces you to learn the TCP handshake, socket states, and why filtered differs from closed — knowledge that's invisible if you only ever run nmap. Understanding the primitive makes you far better at using the polished tool.
